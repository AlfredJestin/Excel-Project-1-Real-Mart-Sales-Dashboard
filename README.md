# Real-Mart Sales Dashboard — Excel

## Project Overview
This project uses Microsoft Excel to analyze sales performance and present key business insights through an interactive dashboard.

## Key Metrics
- Total Sales
- Total Profit
- Number of Orders
- Customer Ratings

## Tools Used
- Microsoft Excel
- PivotTables and charts
- Dashboard design and data visualization

## Project Objective
To summarize sales performance and help users explore trends across cities, branches, product lines, and payment methods.
